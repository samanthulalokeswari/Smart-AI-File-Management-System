# Smart AI File Management System

An AI-powered file management application built using Python and Streamlit.

## Features
- Workspace scanning
- Automatic file organization
- Duplicate file detection
- Reports and analytics
- AI-powered assistance
- CrewAI multi-agent integration

## Technologies Used
- Python
- Streamlit
- CrewAI
- Google Gemini API
- Pandas
- NumPy
- Git and GitHub

## Project Structure
- `app.py` - Main Streamlit application
- `scan.py` - Workspace scanning
- `organize.py` - File organization
- `duplicate.py` - Duplicate detection
- `report.py` - Reports and analytics
- `ai_assistant.py` - AI assistant
- `crew_ai.py` - CrewAI integration
- `utils.py` - Utility functions
- `requirements.txt` - Project dependencies

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Create a `.env` file and configure your `GEMINI_API_KEY`.
5. Start the application:

   `streamlit run app.py`

## Security
Never upload your `.env` file or expose your API key publicly.
